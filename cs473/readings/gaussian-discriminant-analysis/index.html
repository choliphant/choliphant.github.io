9.1 & 9.2 · Introduction and Gaussian discriminant analysis

Model each class, then apply Bayes’ rule.

A generative classifier models the class prior πc = p(y = c) and the class-conditional feature density p(x | y = c). Together they define the joint distribution. You could generate an example by sampling a class and then sampling its features.

p(y = c | x, θ) = πc p(x | y = c, θ) / ∑k πk p(x | y = k, θ)
p(x | y = c, θ) = 𝒩(x | μc, Σc)
Eqs. 9.1–9.3 · GDA chooses a multivariate Gaussian density for every class.

A discriminative classifier instead models p(y | x) directly. GDA is generative even though “discriminant” appears in its name. Here, LDA means linear discriminant analysis.

Score versus probability. The product πc𝒩(x | μc, Σc) is an unnormalized score. Divide by the sum over classes to obtain posterior probabilities. Under equal misclassification costs, the MAP class is the one with the largest score; normalization is unnecessary for that argmax.

Worked example: πA = 0.25 and πB = 0.75. At a particular x, the class densities are 0.6 and 0.1. The scores are 0.15 and 0.075, so p(A | x) = 0.15/0.225 = 2/3. A less common class can win when its likelihood is sufficiently larger.

A Gaussian density value is not the probability of one exact continuous input; density values can exceed 1. Class posterior probabilities still lie between 0 and 1.

9.2.1 · Quadratic decision boundaries

Different covariances preserve quadratic terms.

gc(x) = log πc − ½ log |Σc|
− ½(x − μc)TΣc−1(x − μc)
Eq. 9.4, omitting the common −(D/2)log(2π) term.

The last term is a squared Mahalanobis distance. It measures distance relative to the class’s spread and correlations. The log determinant term accounts for the Gaussian’s volume; spread alone does not make a class more likely everywhere.

For two classes, set gc(x) = gk(x). With separate covariance matrices, the quadratic terms generally remain. This is quadratic discriminant analysis (QDA).

QDA permits quadratic boundaries; special parameter settings can still give a linear boundary. Unequal diagonal covariances can also produce quadratic boundaries.

9.2.2 · Linear decision boundaries

Shared covariance cancels the common quadratic term.

Constrain every class to use the same entire matrix: Σc = Σ. The determinant term and xTΣ−1x are identical across classes, so they cancel when comparing scores.

gc(x) = γc + xTβc
βc = Σ−1μc
γc = log πc − ½μcTΣ−1μc
Eqs. 9.5–9.7 · Class-independent terms omitted.

The pairwise equality is a hyperplane, so this is linear discriminant analysis (LDA). In 2D it is a line. Shared covariance can be full and correlated; it need not be diagonal or spherical.

“Linear” refers to the class comparison and boundary. Normalized class posterior probabilities need not be linear functions of x.

9.2.4 · Model fitting

Use labeled data to fit each class.

The labeled joint log-likelihood separates into a class-prior term and Gaussian terms grouped by class. This lets you optimize π separately from the Gaussian parameters. Let N be the total number of examples and Nc the count in class c.

ℓ(θ) = ∑n log πyₙ + ∑c ∑n:yₙ=c log 𝒩(xn | μc, Σc)
π̂c = Nc/N
μ̂c = (1/Nc) ∑n:yₙ=c xn
Σ̂c = (1/Nc) ∑n:yₙ=c (xn − μ̂c)(xn − μ̂c)T
Eqs. 9.18–9.20 · Gaussian maximum likelihood estimates.

Worked example, one feature: class A has values [0, 2] and class B has [3, 3, 5, 5]. Then π̂A = 1/3, π̂B = 2/3, μ̂A = 1, μ̂B = 4, and both MLE variances are 1. The class means differ, but each class has the same within-class spread.

Keep the denominator straight. The class covariance MLE divides by Nc, not Nc − 1. In D dimensions, its rank is at most min(D, Nc − 1). If there are too few examples, it can be singular and unusable in a Gaussian inverse/determinant calculation.

9.2.4.1–9.2.4.3 · Covariance choices

Reduce what you need to estimate.

ChoiceCovariance parametersGeometry and tradeoff
Separate full matricesC × D(D + 1)/2QDA; each class has its own spread and correlations. Needs more data.
One shared full matrixD(D + 1)/2LDA; pool information across classes while retaining shared correlations.
Separate diagonal matricesC × DDiscard within-class feature correlations; boundaries can remain quadratic.
One shared diagonal matrixDDiagonal LDA; linear boundaries with fewer parameters.

Counts above are for covariance parameters only. Every model also estimates C × D mean coordinates and C − 1 free class-prior parameters.

Tied covariance: pool residuals around the class means.

Σ̂ = (1/N) ∑c ∑n:yₙ=c (xn − μ̂c)(xn − μ̂c)T
= ∑c (Nc/N) Σ̂c
Eq. 9.21 · The tied covariance MLE divides by N.

This is a count-weighted average of class covariance MLEs. It is not the covariance of all inputs around one global mean: between-class mean differences should not inflate the within-class spread.

Diagonal covariance: fewer parameters, fewer correlations.

A diagonal Gaussian covariance makes features conditionally independent within a class. This can help in high dimensions, but discards correlations and does not guarantee immunity to overfitting. Even a tied estimate can be singular when data are insufficient.

MAP estimation: shrink correlations toward zero.

Σ̂map = λ diag(Σ̂mle) + (1 − λ)Σ̂mle,  0 ≤ λ ≤ 1
Eq. 9.22 · The covariance shrinkage form presented in this section.

Here diag(Σ̂) is a matrix retaining only the diagonal. The variances stay unchanged; each off-diagonal covariance is multiplied by (1 − λ). λ = 0 keeps the full estimate, λ = 1 makes it diagonal. This is regularized discriminant analysis (RDA).

Example: if Σ̂ = [[4, 1.2], [1.2, 1]], then λ = 0.5 gives [[4, 0.6], [0.6, 1]]. This shrinkage targets a diagonal matrix, rather than replacing the variances by equal values. Zero diagonal variance can still require additional treatment.

9.2.5 · Nearest centroid classifier

Equal priors plus shared covariance give nearest class means.

With a common covariance and uniform class priors, the only class-dependent part of the Gaussian score is the negative squared Mahalanobis distance:

ŷ(x) = argminc (x − μc)TΣ−1(x − μc)
Eq. 9.23 · Nearest centroid / nearest class mean (NCM).

If Σ = σ²I, minimizing this distance is equivalent to minimizing ordinary Euclidean distance. Otherwise, directions with more variance count less, and correlations affect the metric. Unequal priors add a class preference; unequal covariances add class-specific volume and shape terms.

Worked example: x = (0, 0), μA = (2, 0), μB = (0, 1), and shared Σ = diag(9, 1). Euclidean squared distances are 4 and 1, so Euclidean NCM chooses B. Mahalanobis squared distances are 4/9 and 1, so the Gaussian NCM chooses A.

A useful distance can be learned.

Choose a linear transform T and define d²(x, μc) = ‖T(x − μc)‖². This corresponds to the positive semidefinite metric TTT. The probabilities can be formed by normalizing exp(−d²/2) across classes. The transform can be trained using a discriminative loss.

T is used here to make dimensions explicit: T maps input features into a transformed space. It represents the learned distance idea in Eqs. 9.24–9.26.

One-shot learning: with a useful transform already learned, add a class from a single labeled prototype μc. This depends on the quality of the learned metric; a single prototype is not enough to learn a full class covariance.

9.2.6 · Introductory discussion only

Project first, then classify.

High-dimensional Gaussian fitting can be difficult. Project x ∈ ℝD into z = Wx ∈ ℝK, with K much smaller than D, and fit Gaussian class models in that smaller space. W has shape K × D.

PCA chooses a projection without using class labels. A direction with large overall variation may mix classes. Fisher’s LDA (FLDA) uses class information to find a projection useful for Gaussian classification.

The introduction describes FLDA as a hybrid of discriminative and generative ideas. It gives the limit K ≤ C − 1: two classes allow at most one FLDA dimension. The reason and derivation belong to the skipped material.

Common traps

Check the assumption behind the shortcut.

  • Diagonal ≠ shared. Diagonal removes correlations; tying shares a matrix across classes.
  • LDA can model correlations. Its shared covariance can be full.
  • Nearest Euclidean mean is a special case. Use equal priors and shared spherical covariance.
  • Density ≠ posterior. Include priors and normalize if probabilities are requested.
  • Pooling ≠ global covariance. Center residuals at each class mean.
  • PCA ≠ class separation. Its objective ignores the labels.
Explain LDA’s cancellation in one sentence.

With a shared covariance matrix, the x-quadratic term and log determinant are common to all classes, leaving affine class scores after they are dropped.

Why prefer LDA with limited data?

It estimates a single covariance from pooled within-class residuals rather than estimating a separate matrix for each class. This reduces variance in estimation, at the cost of assuming a common covariance.
