Section 4: Linear Classification & Generative Models

In classification, our goal is to map input vectors $\mathbf{x} \in \mathbb{R}^D$ into discrete class labels $C_k \in \{C_1, \dots, C_K\}$.

1. Generative vs. Discriminative Approaches

  • Generative Approach: Model the class-conditional densities $p(\mathbf{x}\vert{}C_k)$ and class priors $p(C_k)$. Posterior probabilities are recovered via Bayes' theorem: $$p(C_k\vert{}\mathbf{x}) = \frac{p(\mathbf{x}\vert{}C_k)p(C_k)}{\sum_j p(\mathbf{x}\vert{}C_j)p(C_j)} = \sigma\left(\ln \frac{p(\mathbf{x}\vert{}C_1)p(C_1)}{p(\mathbf{x}\vert{}C_2)p(C_2)}\right) \text{ (for $K=2$)}$$
  • Discriminative Approach: Model the posterior $p(C_k\vert{}\mathbf{x})$ directly (e.g., Logistic Regression) without modeling the input distribution $p(\mathbf{x})$.

2. Gaussian Discriminant Analysis (GDA)

Assuming continuous features where each class follows a multivariate normal distribution:

$$p(\mathbf{x}\vert{}C_k) = \frac{1}{(2\pi)^{D/2}\vert{}\boldsymbol{\Sigma}_k\vert{}^{1/2}} \exp\left( -\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x}-\boldsymbol{\mu}_k) \right)$$
  • Tied Covariances ($\boldsymbol{\Sigma}_k = \boldsymbol{\Sigma}$): The quadratic terms in $\mathbf{x}^T \boldsymbol{\Sigma}^{-1} \mathbf{x}$ cancel in the log-odds ratio, producing a linear decision boundary (Linear Discriminant Analysis / LDA).
  • Separate Covariances ($\boldsymbol{\Sigma}_k \neq \boldsymbol{\Sigma}_j$): Quadratic terms persist, resulting in quadratic decision surfaces (Quadratic Discriminant Analysis / QDA).

Section 8: The Expectation-Maximization (EM) Algorithm

EM is a general optimization paradigm for finding Maximum Likelihood (ML) or Maximum A Posteriori (MAP) estimates in models with latent variables $\mathbf{Z}$.

1. The Incomplete-Data Log-Likelihood

Given observed data $\mathbf{X}$ and latent variables $\mathbf{Z}$, our goal is to maximize:

$$\ln p(\mathbf{X}\vert{}\boldsymbol{\theta}) = \sum_{\mathbf{Z}} \ln p(\mathbf{X}, \mathbf{Z}\vert{}\boldsymbol{\theta})$$

The summation inside the logarithm prevents analytically tractability (parameters cannot decouple cleanly).

2. Decomposition and Evidence Lower Bound (ELBO)

For any arbitrary variational distribution $q(\mathbf{Z})$ over the latent variables:

$$\ln p(\mathbf{X}\vert{}\boldsymbol{\theta}) = \mathcal{L}(q, \boldsymbol{\theta}) + \text{KL}(q \,\vert{}\vert{}\, p)$$ $$\mathcal{L}(q, \boldsymbol{\theta}) = \sum_{\mathbf{Z}} q(\mathbf{Z}) \ln \left\{ \frac{p(\mathbf{X}, \mathbf{Z}\vert{}\boldsymbol{\theta})}{q(\mathbf{Z})} \right\}, \quad \text{KL}(q \,\vert{}\vert{}\, p) = -\sum_{\mathbf{Z}} q(\mathbf{Z}) \ln \left\{ \frac{p(\mathbf{Z}\vert{}\mathbf{X}, \boldsymbol{\theta})}{q(\mathbf{Z})} \right\}$$

Because $\text{KL}(q \,\vert{}\vert{}\, p) \ge 0$, $\mathcal{L}(q, \boldsymbol{\theta})$ forms a rigorous lower bound: $\ln p(\mathbf{X}\vert{}\boldsymbol{\theta}) \ge \mathcal{L}(q, \boldsymbol{\theta})$.

3. The Generalized Two-Step Cycle

  1. E-Step (Expectation): Fix parameters $\boldsymbol{\theta}^{(\text{old})}$ and maximize $\mathcal{L}$ with respect to $q(\mathbf{Z})$. This maximum occurs when $\text{KL}(q \,\vert{}\vert{}\, p) = 0$, requiring: $$q(\mathbf{Z}) = p(\mathbf{Z}\vert{}\mathbf{X}, \boldsymbol{\theta}^{(\text{old})})$$
  2. M-Step (Maximization): Keep $q(\mathbf{Z})$ fixed and maximize $\mathcal{L}(q, \boldsymbol{\theta})$ with respect to $\boldsymbol{\theta}$. This is equivalent to maximizing the expected complete-data log-likelihood: $$\boldsymbol{\theta}^{(\text{new})} = \arg\max_{\boldsymbol{\theta}} \mathcal{Q}(\boldsymbol{\theta}, \boldsymbol{\theta}^{(\text{old})}) \quad \text{where } \mathcal{Q}(\boldsymbol{\theta}, \boldsymbol{\theta}^{(\text{old})}) \equiv \mathbb{E}_{\mathbf{Z}\vert{}\mathbf{X},\boldsymbol{\theta}^{(\text{old})}} [\ln p(\mathbf{X}, \mathbf{Z}\vert{}\boldsymbol{\theta})]$$

Section 8.7: Gaussian Mixture Models (GMM)

A canonical application of EM is density estimation with a mixture of $K$ Gaussians:

$$p(\mathbf{x}) = \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x}\vert{}\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k), \quad \text{subject to } \sum_{k=1}^K \pi_k = 1, \; \pi_k \ge 0$$

Latent binary indicators $\mathbf{z}_n \in \{0, 1\}^K$ use a 1-of-$K$ encoding indicating which Gaussian generated observation $\mathbf{x}_n$.

E-Step: Evaluating Responsibilities ($\gamma_{nk}$)

Compute the posterior probability that component $k$ generated point $\mathbf{x}_n$:

$$\gamma_{nk} \equiv \mathbb{E}[z_{nk}] = p(z_{nk}=1\vert{}\mathbf{x}_n, \boldsymbol{\theta}) = \frac{\pi_k \mathcal{N}(\mathbf{x}_n\vert{}\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(\mathbf{x}_n\vert{}\boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)}$$

M-Step: Parameter Closed-Form Updates

Define the effective number of points assigned to cluster $k$ as $N_k = \sum_{n=1}^N \gamma_{nk}$:

$$\boldsymbol{\mu}_k^{(\text{new})} = \frac{1}{N_k}\sum_{n=1}^N \gamma_{nk}\mathbf{x}_n$$ $$\boldsymbol{\Sigma}_k^{(\text{new})} = \frac{1}{N_k}\sum_{n=1}^N \gamma_{nk}(\mathbf{x}_n - \boldsymbol{\mu}_k^{(\text{new})})(\mathbf{x}_n - \boldsymbol{\mu}_k^{(\text{new})})^T$$ $$\pi_k^{(\text{new})} = \frac{N_k}{N}$$

Synthesis & Exam Review

Concept Key Formula / Characteristic Failure Modes / Gotchas
Monotonicity $\ln p(\mathbf{X}\vert{}\boldsymbol{\theta}^{(t+1)}) \ge \ln p(\mathbf{X}\vert{}\boldsymbol{\theta}^{(t)})$ guaranteed. Guarantees convergence to a local maximum or saddle point, not global optimum.
GMM vs. K-Means K-Means is the limit of EM for GMM as variances $\sigma^2 \to 0$ (hard assignments). GMM accounts for cluster scales and covariance orientations that K-Means cannot.
Singularities in GMM A component variance collapses to zero on a data point: $\sigma_k^2 \to 0 \implies \mathcal{N} \to \infty$. Does not occur in discrete models; requires variance floor regularization or Bayesian priors.
Classification Connection GDA models class-conditional distributions with known labels. EM fits the same generative densities when class identities are unobserved (unsupervised).

Fast Self-Check Quiz

  1. Why does the log-likelihood decompose with an inequality?
    Because $\text{KL}(q\vert{}\vert{}p) \ge 0$ via Jensen's inequality, making $\mathcal{L}(q, \boldsymbol{\theta})$ a lower bound.
  2. What is the computational role of the E-step?
    It computes the expectations of the latent variables conditioned on the current parameters, decoupling the log-sum-exp problem.
