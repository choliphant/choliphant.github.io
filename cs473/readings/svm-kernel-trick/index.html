The kernel trick

Change the geometry.
Keep the dot products.

A nonlinear feature map can make a linear classifier more expressive. A kernel computes the dot products in that feature space, so you can use the classifier without constructing the mapped vectors.

§17.3.4 · printed p. 590

A dot product without the feature vector.

K(x, z) = φ(x)Tφ(z)

x and z are original inputs. The function φ maps each input to a feature vector, possibly in a much larger or infinite-dimensional space. K takes the two original inputs and returns one scalar: the dot product of their mapped features.

Explicit route
x, z → φ(x), φ(z) → dot product
=
Kernel route
x, z → K(x, z)

If the learning algorithm only needs these dot products, it can use K directly. We do not have to store φ(x), or even write its coordinates down. That computational substitution is the kernel trick.

Say it aloud: “Replace inner products with a valid kernel. This is equivalent to working linearly in an implicit feature space, which can produce nonlinear behavior in the original input space.”

Main reading: §17.3.4, p. 590, Eqs. 17.93–17.94. Feature-map reminder: §17.1.1, pp. 568–569 / PDF pp. 598–599. We use z for the book’s second input x′.

Skim · §17.3.2 · pp. 587–589

Why do dot products appear?

The ordinary linear SVM has a weight vector w and bias b (the book writes w₀). The dual instead learns one nonnegative coefficient αᵢ per training example.

w = ∑ᵢ αᵢyᵢxᵢ
f(x) = ∑i∈S αᵢyᵢ(xᵢTx) + b

Here labels yᵢ are −1 or +1 (the book uses ỹᵢ). S contains the support vectors, the examples with αᵢ > 0. Terms with αᵢ = 0 contribute nothing.

The result to keep: both the dual training objective and prediction depend on inputs through pairwise dot products. You do not need to reproduce the Lagrangian derivation for this guide’s goal.

Eqs. 17.73–17.82. Hard-margin dual: αᵢ ≥ 0 and ∑ᵢαᵢyᵢ = 0. A support vector lies on a margin boundary yᵢf(xᵢ) = 1, not the decision boundary f(x) = 0; the wording on p. 588 is imprecise.

Skim · §17.3.3 · pp. 589–590

Allow violations when separation is imperfect.

A hard-margin SVM insists on yᵢf(xᵢ) ≥ 1 for every training point. A soft-margin SVM introduces nonnegative slack ξᵢ:

min   ½‖w‖² + C∑ᵢξᵢ
subject to ξᵢ ≥ 0 and yᵢf(xᵢ) ≥ 1 − ξᵢ.

Larger C puts more weight on penalizing margin violations. Smaller C allows a wider margin at greater tolerance for violations. C is a penalty strength, not a count of permitted mistakes.

The dual still uses dot products, but now 0 ≤ αᵢ ≤ C. If 0 < αᵢ < C, that point is on the margin. A point with αᵢ = C may be inside the margin or misclassified; it is still a support vector.

A margin violation need not be a wrong label: 0 < yᵢf(xᵢ) < 1 is correctly classified but inside the margin. The minimum required slack is max(0, 1 − yᵢf(xᵢ)). At f(xᵢ) = 0, the point is on the decision boundary.

Eqs. 17.83, 17.85–17.88. The ν-SVM paragraph introduces an alternative parameterization; recognize it as a variant, then continue to §17.3.4.

Focus · §17.3.4 · p. 590

Replace dot products in training and prediction.

Conceptually, map x to φ(x) and fit a linear SVM there. Algebraically, every φ(xᵢ)Tφ(xⱼ) becomes K(xᵢ, xⱼ).

WhereOriginal-input linear SVMKernel SVM
Training interactionxᵢTxⱼK(xᵢ, xⱼ)
Prediction interactionxᵢTxK(xᵢ, x)
Score∑i∈S αᵢyᵢxᵢTx + b∑i∈S αᵢyᵢK(xᵢ, x) + b
Decisionsign(f(x))sign(f(x))

The α values and b are learned using the chosen kernel. Changing the kernel generally requires retraining; it is not just a prediction-time substitution using the old fitted coefficients.

The dual objective after substitution

maximizeα   ∑ᵢ αᵢ − ½∑ᵢ∑ⱼ αᵢαⱼyᵢyⱼK(xᵢ, xⱼ)
Soft margin: 0 ≤ αᵢ ≤ C, and ∑ᵢαᵢyᵢ = 0.

This is Eq. 17.85 with its dot product replaced. The Gram matrix K has entry Kᵢⱼ = K(xᵢ, xⱼ). With N training inputs, it is N × N regardless of the feature-space dimension. For one new input x, prediction uses the N × 1 vector of train–test kernel values; only entries for support vectors contribute.

The bias must use the same kernel

b = yᵢ − ∑j∈S αⱼyⱼK(xⱼ, xᵢ)
Choose a support vector on the margin; average these estimates when several are available.

For hard margin, use S as in Eq. 17.94. For soft margin, average over the free support vectors M = {i : 0 < αᵢ < C}, following Eq. 17.88. A point at αᵢ = C need not satisfy yᵢf(xᵢ) = 1, so blindly averaging over every support vector is incorrect. The displayed formula requires at least one eligible point.

§17.3.4, Eqs. 17.93–17.94; §17.3.3, Eqs. 17.85–17.88. Matrix dimensions are explanatory bookkeeping.

Original arithmetic · supporting §17.1.1 example

Two routes, the same number.

Use the homogeneous quadratic kernel K(x, z) = (xTz)². For two-dimensional inputs, a matching feature map is

φ(x₁, x₂) = [x₁², √2 x₁x₂, x₂²]T.

Direct kernel route

Let x = (1, 2) and z = (3, 4).

xTz = 1·3 + 2·4 = 11
K(x, z) = 11² = 121

Explicit feature route

φ(x) = (1, 2√2, 4)
φ(z) = (9, 12√2, 16)
φ(x)Tφ(z) = 9 + 48 + 64 = 121

The √2 factor makes the mixed term equal 2x₁x₂z₁z₂. Dropping it changes the dot product. Notice the result is not (x ⊙ z), a vector, and it is not an explicit mapped point: K returns one scalar.

What the shortcut saves: for D-dimensional inputs, an explicit homogeneous degree-two map has D(D + 1)/2 coordinates. For D = 100, that is 5,050 features, while (xTz)² requires a 100-coordinate dot product and a square. This is a per-pair saving; the training Gram matrix still has N² entries.

Feature-map identity: §17.1.1, Eq. 17.6, pp. 568–569 / PDF pp. 598–599. Inputs, arithmetic, feature count, and cost comparison are original explanatory examples.

Original geometry example

Linear in feature space can be nonlinear in input space.

Place positive labels at (1, 1) and (−1, −1), and negative labels at (1, −1) and (−1, 1). This XOR pattern cannot be separated by one straight line in the original plane.

After the quadratic map, the middle coordinate √2 x₁x₂ has opposite signs for the two classes. A plane using that coordinate separates the mapped points.

f(x) = x₁x₂
Feature space: f(x) = (0, 1/√2, 0)Tφ(x)
Input space boundary: x₁x₂ = 0

The boundary in input space is the union of the two coordinate axes. This is an exact small kernel SVM example used in the lab, not a claim that every nonlinear dataset becomes perfectly separable.

Original illustration of §17.3.4. The kernel lab shows its support-vector sum and checks its training margins.

A few useful kernels

The kernel chooses the feature geometry.

Linear: K(x, z) = xTz
Quadratic: K(x, z) = (xTz)²
RBF: K(x, z) = exp(−‖x − z‖² / (2ℓ²))

The linear kernel leaves you in the original feature space. The quadratic kernel introduces second-order products. The RBF kernel corresponds to an infinite-dimensional feature representation, although each K(x, z) is a finite scalar calculation.

A kernel can also compare strings or graphs without an explicit fixed-length feature vector. It must still satisfy the kernel-validity condition.

Supporting concept · §17.1

“Similarity” alone is not enough.

For real-valued feature-space dot products, K must be symmetric and every finite Gram matrix must be positive semidefinite (PSD):

K(x, z) = K(z, x)
cTKc ≥ 0   for every coefficient vector c and every finite input set.

If Kᵢⱼ = φ(xᵢ)Tφ(xⱼ), then cTKc = ‖∑ᵢ cᵢφ(xᵢ)‖² ≥ 0. This is why the condition is tied to dot products. A Gram matrix may have zero eigenvalues; strict positivity is not required for ordinary kernel methods.

A failed candidate

K = [ 1   2 ;   2   1 ]
c = (1, −1)
cTKc = 1 − 4 + 1 = −2

Every entry is positive and the matrix is symmetric, but it fails the PSD test. The kernel lab lets you change c.

What a finite check can establish

One negative value disproves validity. Passing on one dataset does not prove a candidate function is a valid kernel on every possible input set. Familiar valid kernels come with a mathematical justification, such as an explicit feature map.

A valid kernel can have negative off-diagonal entries; the linear kernel on x = (1, 0), z = (−1, 0) gives K(x, z) = −1. PSD concerns the whole quadratic form.

§17.1, Eq. 17.1, pp. 567–568 / PDF pp. 597–598. Terminology clarification: the book says “positive definite (Mercer)”; here PSD includes the zero-eigenvalue cases needed for its linear and polynomial examples. Counterexample and proof sketch are explanatory additions.

Before the quiz

Keep these distinctions straight.

Kernel ≠ mapped vector.

K(x, z) is a scalar dot product. φ(x) is a vector. The trick skips constructing the latter.

Prediction ≠ a weighted probability average.

Compute αᵢyᵢK(xᵢ, x), sum the signed contributions, add b, then take the sign. The coefficients are not normalized to sum to one.

Kernelizing ≠ keeping the old fit.

Train with K in the objective and use K in prediction and the bias formula. A new kernel usually changes α, b, and which points are support vectors.

Margin ≠ decision boundary.

The decision boundary is f(x) = 0. Canonical SVM margins are f(x) = ±1. A correctly classified point may still violate a margin.

Implicit ≠ free computation.

Kernel evaluation avoids explicit expanded features. A dense N × N Gram matrix still costs O(N²) storage, and large-N training can be expensive.

Nonlinear ≠ guaranteed success.

A linear kernel gives a linear boundary; a nonlinear kernel permits more complex boundaries but does not guarantee perfect separation or good generalization.

Connection to the previous GP reading: a compatible kernel can define covariance for a GP or dot products for an SVM. The learning procedures differ: GP regression conditions a distribution; an SVM learns a margin classifier. The shared kernel does not make their predictions identical.
