9.3 · Naive Bayes classifiers

Features are independent after conditioning on the class.

For class c, naive Bayes replaces a potentially complicated joint feature distribution with a product of one-feature distributions. Features can still be dependent overall because they share the class label.

p(x | y = c, θ) = ∏d=1…D p(xd | y = c, θdc)
Eq. 9.46 · Conditional independence is the modeling assumption.

Let πc = p(y = c). To classify a new input, combine the prior with the likelihood and normalize across classes:

sc = πc ∏d p(xd | y = c)
p(y = c | x) = sc / ∑c′ sc′
Eq. 9.47 · Predict the class with the largest posterior.

Watch the conditioning. “Naive” does not mean the features are independent without knowing y. Even when the assumption is imperfect, a small model can classify well. Under a fixed number of states per feature, the parameter count grows on the order of C × D.

Textbook p. 332 · §9.3

9.3.1 · Example models

Match each feature to a distribution.

  • Binary: Bernoulli; θdc is the probability that feature d equals 1 in class c.
  • Categorical: Categorical; θdck is the probability of state k in class c.
  • Real-valued: Univariate Gaussian; one mean μdc and variance σ²dc for each feature and class.

Gaussian naive Bayes is Gaussian discriminant analysis with diagonal covariance matrices. The per-class variances need not be the same across classes.

Ber(xd | θdc) = θdcxd(1 − θdc)1−xd

An observed 0 contributes 1 − θ. An unobserved value will be marginalized instead.

Textbook pp. 332–333 · §9.3.1

9.3.2 · Model fitting

Count or average within each class.

The labeled-data log-likelihood separates into a term for the class prior and a term for every feature/class pair. Each parameter group can therefore be fitted independently.

ℓ(θ) = ∑n log πyₙ + ∑c,d ∑n:yₙ=c log p(xnd | θdc)

N: total examples; Nc: examples in class c; Ndck: class-c examples with feature d in state k.

π̂c = Nc / N
θ̂dck = Ndck / Nc
μ̂dc = (1/Nc) ∑n:yₙ=c xnd
σ̂²dc = (1/Nc) ∑n:yₙ=c (xnd − μ̂dc)²

These are MLEs. The variance uses Nc, rather than the Nc − 1 denominator of the unbiased sample variance.

Textbook pp. 333–334 · Eqs. 9.48–9.55

9.3.3 · Bayesian naive Bayes

Turn prior pseudocounts into predictive probabilities.

For categorical features, place independent Dirichlet priors on each θdc, and a Dirichlet prior on π. Conjugacy gives posterior parameters by adding the observed counts to the prior parameters.

θdc | 𝒟 ~ Dir(βdc + Ndc·)
π | 𝒟 ~ Dir(α + N·)

Here β and α denote the prior pseudocounts. A vector of feature-state counts is written Ndc·.

θ̄dck = (Ndck + βdck) / (Nc + ∑k′ βdck′)
π̄c = (Nc + αc) / (N + ∑c′ αc′)

These posterior means give the one-example posterior predictive probabilities after integrating out the parameters.

Laplace smoothing: set every feature-state pseudocount to 1. For a K-state feature, use (Ndck + 1)/(Nc + K). For a binary feature, use (Ndc1 + 1)/(Nc + 2).

Worked example. A three-state feature has class-specific counts [0, 2, 6]. MLE gives [0, ¼, ¾]. Add-one smoothing gives [1/11, 3/11, 7/11]. The unseen state now has positive probability, so it no longer forces the entire class likelihood to zero.

This smoothing formula is a posterior mean/predictive formula, not the Dirichlet MAP formula. Setting pseudocounts to zero recovers the MLE expression algebraically; all-zero Dirichlet parameters do not define a proper prior.

Textbook pp. 334–335 · Eqs. 9.56–9.59

9.3.4 · Connection to logistic regression

A product of categorical probabilities becomes a softmax.

One-hot encode each discrete feature: xdk = 1 when feature d takes state k. Taking logs turns products into sums:

ac(x) = log πc + ∑d,k xdk log θdck
p(y = c | x) = exp(ac) / ∑c′ exp(ac′)
Eqs. 9.60–9.62 · Linear scores in the one-hot feature representation.

Set the bias to log πc and the feature weights to log θdck. The resulting posterior has the same softmax form as multinomial logistic regression. The training objectives still differ:

Naive BayesLogistic regression
Fit the joint likelihood ∏n p(xn, yn).Fit the conditional likelihood ∏n p(yn | xn).
Weights come from estimated generative probabilities.Weights are optimized directly for conditional prediction.

Same posterior form does not imply the same fitted predictions. For more general exponential-family features, the corresponding sufficient-statistic representation matters; do not assume every Gaussian naive Bayes classifier is linear in raw x.

Implementation tip: compute class scores in log space and normalize with log-sum-exp to avoid multiplying many tiny numbers.

Textbook p. 336 · §9.4

9.4.1 · Discriminative advantages

Focus effort on the prediction.

  • Often better predictive accuracy: p(y | x) can be simpler to learn than the full joint distribution.
  • Flexible preprocessing: engineered features and embeddings can be used without modeling their full distribution.
  • Often better calibration: incorrect independence assumptions can make naive Bayes excessively confident. Logistic regression often gives more reliable probabilities.

Calibration asks whether, among predictions assigned about 80% probability, roughly 80% are correct. A good classification accuracy does not guarantee this.

These are tendencies, not guarantees. Discriminative probabilities may also need calibration.

Textbook pp. 336–337 · §9.4.1

9.4.2 · Generative advantages

Model the data to gain other capabilities.

  • Simple fitting for models such as naive Bayes: counts and averages.
  • Missing inputs: marginalize unobserved features.
  • Separate class fitting: add a class density without refitting existing class densities; update or renormalize class priors.
  • Unlabeled data: use p(x) = ∑c p(x, c) in semi-supervised learning.
  • Potential robustness: a suitable generative model may capture stable mechanisms rather than spurious training correlations.

These benefits depend on the model. A generative model is not automatically easy to fit, causal, or robust; naive Bayes illustrates the simple case.

Textbook p. 337 · §9.4.2

9.4.3 · Handling missing features

Sum out the unknown, rather than treating it as zero.

Separate the input into observed features xO and missing features xM. A generative classifier can compute the likelihood of what was observed by marginalizing the rest:

p(y = c | xO) ∝ πc ∑xM p(xO, xM | y = c)
Use an integral for continuous missing features.

Under naive Bayes, every missing-feature factor sums or integrates to 1. Therefore the posterior only needs the observed-feature factors:

p(y = c | xO) ∝ πc ∏d∈O p(xd | y = c)
Eqs. 9.63–9.65 · Drop the missing likelihood factors, then normalize.

Assumption: this treatment assumes the missingness is not informative about the feature’s potential value. If the missingness pattern carries class information, simply discarding it may discard evidence.

Binary example. If θdc = 0.8, an observed 1 contributes 0.8, an observed 0 contributes 0.2, and a missing value contributes 0.8 + 0.2 = 1. If every feature is missing, prediction returns the class prior.

A complete prediction

Two binary features, two classes.

Suppose p(spam) = 0.4 and p(ham) = 0.6. Feature likelihoods for x1 = 1 are 0.8 vs 0.2; for x2 = 1 they are 0.6 vs 0.1. For x = (1, 1):

  1. MultiplySpam: 0.4 × 0.8 × 0.6 = 0.192.
    Ham: 0.6 × 0.2 × 0.1 = 0.012.
  2. NormalizeThe evidence is 0.192 + 0.012 = 0.204.
    p(spam | x) = 0.192 / 0.204.
  3. Predictp(spam | x) ≈ 0.9412.
    Predict spam; confidence depends on the model’s assumptions.

Common exam traps

“Independent features” without conditioning

The assumption is conditional on y. Mixing classes can produce dependence even when features are independent within each class.

Adding 1 only to the numerator

Add one pseudocount to each of the K states. The denominator becomes Nc + K, so the probabilities still sum to 1.

Replacing a missing binary value with 0

Zero is an observed state with likelihood 1 − θ. Missing means sum over both states; its factor is 1 under naive Bayes.

Calling all generative boundaries linear

Model family and parameter restrictions determine boundary shape. Class-specific Gaussian variances can produce quadratic scores in raw features.

Assuming the higher-accuracy model is calibrated

Classification accuracy evaluates the winning class; calibration evaluates the meaning of predicted probabilities.

Smoothing lab · §9.3.3

What happens to an unseen state?

A three-state categorical feature has counts [0, 2, 6] within one class. Add the same pseudocount β to each state.

p(k | class, 𝒟) = (Nk + β) / (8 + 3β)

Positive β gives a proper symmetric Dirichlet prior. The β = 0 option shows the MLE limit, rather than a proper Dirichlet prior.
