Start here

Stored examples become a generative model.

  1. Smooth each exampleCenter a density kernel at every stored input. Bandwidth h controls how far each example spreads its mass.
  2. Average the kernelsThe resulting p(x | D) is a normalized density. Sample a stored example uniformly, then sample its centered kernel.
  3. Condition to predictClass conditional densities lead to classification. A joint density over input and response leads to kernel regression.

16.3.1 · Density kernels

A unit of probability mass, with adjustable width.

A density kernel K(u) is nonnegative, symmetric about zero, and integrates to one. Symmetry makes its mean zero when the first moment exists; shifting it to xn makes its mean xn.

K(u) ≥ 0,   K(−u) = K(u),   ∫ K(u) du = 1
Kh(u) = (1/h) K(u/h),   h > 0
∫ x Kh(x − xn) dx = xn

Changing h stretches the horizontal axis and rescales the height by 1/h. Without that height correction, the area would grow with h. For a Gaussian, h is the standard deviation and h² is the variance.

With this boxcar convention, Kh(x − xn) = 1/(2h) for |x − xn| ≤ h. The interval has half-width h and total width 2h. Use Eq. 16.28 to resolve informal descriptions of window size.

More than one input dimension

Kh(v) = [hD(2π)D/2]−1 exp(−‖v‖² / (2h²))
Isotropic Gaussian: covariance h²I. In D dimensions the normalization uses hD, not h.

The book introduces radial kernels through distance from the origin. A valid multivariate density still needs the correct dimension dependent normalization. A “density kernel” here has specific probability requirements; the word kernel has other meanings elsewhere in machine learning.

16.3.2 · Parzen windows

One center per example.

p̂(x | D) = (1/N) ∑n=1N Kh(x − xn)

KDE is also called a Parzen window estimator. A Gaussian KDE is a mixture of N Gaussians with equal weights 1/N, means fixed at the observed xn, and shared covariance h²I. It does not optimize a separate set of cluster centers.

Each kernel integrates to one, so the average integrates to (1/N) × N = 1. Density at a point is a height, not a probability; a density can exceed one. Probabilities come from integrating over a region.

Worked example · boxcar KDE

Use xn ∈ {0, 1, 3}, h = 1, and query x = 0.5. Two examples lie within distance 1. Each contributes 1/(2h) = 0.5:

p̂(0.5) = (0.5 + 0.5 + 0)/3 = 1/3.

A value 1/3 is a density per unit x. It is not P(X = 0.5); this continuous model assigns probability zero to a single point.

16.3.2 · Practical meaning

Simple construction, growing cost.

“Nonparametric” does not mean parameter free: h still matters. The representation grows with N, rather than keeping a fixed number of learned mixture components.

  • Storage: retain the training inputs; O(ND) for N dense D dimensional vectors.
  • Evaluation: a direct Gaussian KDE query computes N kernels, typically O(ND).
  • Compact support: sufficiently distant points contribute zero; indexing can help exploit this.
  • Generation: pick n uniformly, then draw X = xn + ε, where ε has density Kh. For Gaussian KDE, ε ∼ N(0, h²I).

There is no center fitting step, but choosing bandwidth is still a modeling decision. KDE defines p(x); it does not need class labels to estimate an input density.

16.3.3 · Choosing bandwidth

How much should nearby examples blend?

ChoiceDensity estimateTypical tradeoff
Small hNarrow peaks; more local detail and possible gaps.Lower smoothing bias, higher sampling variance.
Large hBroad peaks; modes can blend together.Higher smoothing bias, lower sampling variance.

These are general trends, not guarantees about every data set. The book’s rule below assumes a 1D Gaussian data distribution and a Gaussian kernel. It is a reference bandwidth, not a universal optimum for all shapes or tasks.

h = σ (4 / (3N))1/5
MAD = mediann |xn − median(x)|
σ̂ = 1.4826 × MAD
For the robust version, substitute σ̂ for σ.

Worked example · slow change with sample size

For N = 100 and σ = 2, h ≈ 0.843. If N grows by 32× at the same σ, the bandwidth halves because 32−1/5 = ½. Doubling σ doubles h.

For D dimensions, the section suggests estimating hd separately for each dimension and using their geometric mean:

h = (∏d=1D hd)1/D

Feature units matter when using one scalar h across dimensions. The geometric mean is the specific heuristic described here; it does not remove scale differences. A robust scale can be zero for repeated data, producing h = 0; the KDE requires h > 0, so this case needs an explicit fallback.

16.3.4 · KDE → KNN classification

Fix the count. Let the neighborhood grow.

Fixed bandwidth KDE chooses a window size and counts examples. The KNN derivation reverses this: grow a region around the query x until it contains K examples across all classes. Call its volume V(x), with Nc(x) local class c examples and Nc class c examples in the full data set.

p̂(x | y = c, D) = Nc(x) / [Nc V(x)]
p̂(y = c) = Nc / N
p̂(y = c | x, D) = [Nc(x)/(N V(x))] / [K/(N V(x))] = Nc(x)/K

Both the total class count and shared query volume cancel when Bayes’ rule normalizes over classes. That is the ordinary KNN vote fraction. The book calls the query dependent construction a balloon estimator; the volume changes with the query, not just with the class.

Worked example · counts that cancel

N = 100, NA = 80, NB = 20. A shared region of volume V = 2 contains 3 A and 2 B examples (K = 5).

p̂(x | A) = 3/(80 × 2) = 0.01875; prior A = 0.8 → product = 0.015
p̂(x | B) = 2/(20 × 2) = 0.05; prior B = 0.2 → product = 0.010
p̂(A | x) = 0.015/0.025 = 0.6 = 3/5.

The vote fraction requires empirical priors Nc/N and the same neighborhood for every class. Changing the priors generally changes the posterior. Growing a separate region per class breaks this cancellation. Boundary ties need a consistent neighbor selection rule.

16.3.5.1 · Nadaraya–Watson mean

Normalize similarity, then average responses.

Start from paired observations (xn, yn). Estimate their joint density with a product kernel. The first factor measures input proximity; the second spreads mass around the observed response.

p̂(x, y | D) = (1/N) ∑n Kh(x − xn) Kh(y − yn)
μ(x) = E[Y | x, D] = [∫ y p̂(x, y) dy] / [∫ p̂(x, y) dy]

Integrating each response kernel gives 1. Integrating y times that kernel gives yn, because its center is its mean. The 1/N factors cancel:

wn(x) = Kh(x − xn) / ∑j Kh(x − xj)
μ(x) = ∑n wn(x)yn,   ∑n wn(x) = 1

This is the Nadaraya–Watson (N-W) estimator, also called kernel regression or kernel smoothing. Where the denominator is positive, its prediction is a convex average of the stored responses, so it lies between their minimum and maximum. A boxcar with no nearby examples gives a zero denominator and an undefined prediction.

Worked example · numerator is not enough

Suppose raw input kernel values are (1, 2, 1) and responses are (2, 4, 8). The normalized weights are (¼, ½, ¼), so μ = 0.5 + 2 + 2 = 4.5. The unnormalized numerator 18 is not the N-W prediction.

Multiplying all input kernel values by the same positive constant leaves N-W unchanged. The normalization cancels that constant. For tiny Gaussian values far from the data, stable arithmetic is needed even though the mathematical denominator is positive.

16.3.5.2 · Predictive variance

Within each kernel, plus between responses.

With Gaussian response kernels centered at yn and common variance σy², the conditional distribution is a mixture whose weights are wn(x). The response variance includes each kernel’s own spread and the disagreement among its centers.

E[Y² | x, D] = σy² + ∑n wn(x)yn²
Var[Y | x, D] = σy² + ∑n wn(x)yn² − μ(x)²
= σy² + ∑n wn(x)(yn − μ(x))²

The book writes σ² for the Gaussian response variance. Here σy² distinguishes it from the input bandwidth hx used in the lab. Allowing separate input/response scales is an explanatory extension of the shared-kernel notation.

Worked example · continue the same weights

With weights (¼, ½, ¼), responses (2, 4, 8), and σy = 1: ∑ wnyn² = 1 + 8 + 16 = 25. Mean μ = 4.5 gives variance 1 + 25 − 20.25 = 5.75. The predictive standard deviation is √5.75 ≈ 2.398.

If all yn are equal, the between-center variance is zero but the predictive variance remains σy². This is the spread of the fitted conditional distribution, not a confidence interval for an estimated mean. A variance does not make a multimodal mixture Gaussian.

16.3.5.3 · Locally weighted regression

Fit a local line at the query.

Equation 16.46 first considers dropping N-W’s denominator: ∑n ynKh(x − xn). This is an unnormalized weighted sum: duplicating the entire training set doubles it, whereas N-W stays the same.

A different idea is to use the input kernels as weights in a local least squares fit. For a scalar input, use φ(x) = [1, x]T and fit an intercept and slope for each query:

β̂(x) = arg minβ ∑n Kh(x − xn) [yn − βTφ(xn)]²
μ̂local(x) = β̂(x)Tφ(x)

The weights depend on the query, so the fitted coefficients can change as x moves. With positive weights on at least two distinct scalar inputs, the line fit is identifiable. If the local design is singular, a unique local line cannot be recovered without an additional choice.

Reading Eq. 16.47 carefully: the printed equation labels the minimized squared error as μ(x). That minimum is a fit error, not the predicted response. The two-step expression above states the intended local regression: find the minimizing coefficients, then evaluate the line at x.

Worked example · a boundary query

Use (0, 1), (1, 3), (2, 5), which lie exactly on y = 1 + 2x. At x = 0 and Gaussian h = 1, N-W gives ≈ 2.007 because all responses exceed or equal 1. A well-defined local line recovers the exact line and predicts 1, with zero weighted residual error.

The book relates this to locally linear regression and LOWESS/LOESS, often used to show local trends in scatter plots. N-W is locally constant; fitting a slope can reduce boundary bias. A local line is not constrained to stay within the observed response range and can extrapolate poorly far from data.

Keep the distinctions straight

Seven mistakes worth catching.

MistakeRepair
“A density height must be ≤ 1.”Its integral must be 1; its height can be larger.
“Wider kernels have the same height.”Use 1/h in 1D, or 1/hD for an isotropic D dimensional kernel.
“KDE learns N cluster means.”In ordinary KDE, centers are the stored data. Choose the bandwidth.
“KNN fixes the neighborhood volume.”It fixes K and adapts the query’s region to include K examples.
“N-W uses raw similarities as weights.”Normalize similarities across examples at the query.
“Predictive variance is only response disagreement.”Add the response kernel’s own variance σy².
“The minimized local SSE is the prediction.”Evaluate the fitted line. The objective measures its fit.
