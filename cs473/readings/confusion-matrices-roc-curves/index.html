2. Mastery Assessment Quiz

Q1: Extreme Threshold Dynamics
If you set the decision threshold τ to be greater than all sample scores (τ > 1.0), what is the resulting (FPR, TPR) coordinate on the ROC space?

Correct! When τ > max(score), the model predicts every single sample as Negative. Therefore, TP = 0 (so TPR = 0) and FP = 0 (so FPR = 0). The curve always begins at (0, 0).

Q2: Metric Dependencies
Why does a severe class imbalance (e.g., test set contains 99% negatives and 1% positives) leave the ROC curve unchanged compared to a balanced set with identical score distributions per class?

Correct! TPR evaluates performance strictly across the column of true positives, and FPR evaluates performance strictly across true negatives. Changes in class prevalence do not shift the marginal rates $p(\hat{Y}=1|Y=1)$ and $p(\hat{Y}=1|Y=0)$.

Q3: Calculating Rates
Suppose a validation set has 50 true positives and 50 true negatives. At a given threshold, the classifier produces 10 False Positives and 5 False Negatives. What are the TPR and TNR?

Correct!
Positives = 50 ⇒ TP = 50 - FN = 50 - 5 = 45 ⇒ TPR = 45/50 = 0.90.
Negatives = 50 ⇒ TN = 50 - FP = 50 - 10 = 40 ⇒ TNR = 40/50 = 0.80 (FPR = 0.20).

Q4: Probabilistic Interpretation of AUC
According to Murphy PML §5.1.3.2, what is the exact probabilistic interpretation of the Area Under the ROC Curve (AUC)?

Correct! AUC corresponds directly to the Wilcoxon-Mann-Whitney rank statistic: $\text{AUC} = P(f(x^+) > f(x^-))$. An AUC of 0.5 represents a random guess.
