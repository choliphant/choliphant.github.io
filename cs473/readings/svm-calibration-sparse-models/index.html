§17.3.5 · p. 591 / PDF p. 621

A margin score is not a probability.

A binary SVM produces a real score f(x); its sign gives a class label. A large positive score is strong evidence according to the fitted decision rule, but the SVM objective does not make f(x) equal to the log-odds of the class.

ŷ = sign(f(x))
p(y = 1 | x) ≈ σ(a f(x) + b),   σ(t) = 1 / (1 + e−t) · Eq. 17.95

Platt scaling fits the two calibration parameters a and b by maximum likelihood on separate validation predictions. Here b is a calibration intercept, distinct from the SVM's own bias inside f. The sigmoid puts outputs between 0 and 1; that range alone does not establish calibration. A calibrated 80% prediction should be correct about 80% of the time among comparable predictions.

Keep calibration data separate from data used to fit the SVM. A practical extension is to use out-of-fold predictions for calibration; an untouched test set is still needed for final evaluation. Do not fit the calibrator on the SVM's own training scores.

Worked arithmetic · original

For f = 2, a = 0.5, b = −1, the calibrated logit is 0.5·2 − 1 = 0, giving p = 0.5. Applying σ directly to f would instead give about 0.881. Neither number is justified without fitting and evaluating the calibration map.

Same classification error, different probabilities

The book's example uses p(x|y=0) = Unif(0,1) and p(x|y=1) = Unif(0.5,1.5). With equal class priors, the true posterior is 0 left of the overlap, 0.5 inside (0.5,1), and 1 right of it. The overlap has total probability 0.5, so Bayes error is 0.5·0.5 = 25%. Correctly finding a decision boundary does not guarantee correct probabilities.

Calibration takeaway: Murphy's Figure 17.15 illustrates a calibration failure. Read it as a warning about interpreting scores and a particular example, rather than proof that every fitted Platt calibrator fails. A probabilistic model also needs calibration checks.

§17.3.5, Eq. 17.95 and Figure 17.15. Equal priors are made explicit to justify the example's posterior and 25% risk; arithmetic and evaluation advice are explanatory additions.

§17.3.6 · pp. 591–592 / PDF pp. 621–622

The margin unifies the two losses.

Use signed labels ỹ ∈ {−1,+1} and define the signed margin m = ỹ f(x). Positive m means the sign agrees with the label; m ≥ 1 means the usual unit-margin constraint is satisfied. A positive but small margin can be correctly classified and still incur hinge loss.

ℓhinge(m) = max(0, 1 − m)
ℓlog(m) = log(1 + e−m)
J(w) = ∑n ℓ(ỹₙ f(xₙ)) + λ ‖w‖²,   λ = 1/(2C)

The λ relationship follows by dividing the standard SVM objective ½‖w‖² + C∑ℓ by C. It assumes a summed loss. A library using a mean loss or another factor convention may use a different numerical relationship. The SVM bias is typically unpenalized.

Margin mHingeLogistic, natural logInterpretation

0.50.5≈ 0.474Correct sign, inside unit margin

Both losses are convex in the score. Hinge has a kink at m = 1 and needs a subgradient or an optimizer that handles the nonsmooth objective. Its flat region makes points strictly beyond the margin exert zero direct loss gradient, which supports a sparse dual expansion over training examples. This does not mean the primal feature weight vector w has many zeros. Logistic loss stays positive at every finite margin and has a nonzero score derivative.

§17.3.7 · pp. 592–593 / PDF pp. 622–623

Binary decisions need an aggregation rule.

Let M be the number of classes, to avoid confusing it with the regularizer C.

One-versus-rest (OvR)

M classifiers
ŷ(x) = arg maxc fc(x)

Classifier c learns “class c” versus all other classes. Multiple binary scores can be positive, or all can be negative. The argmax still gives a label if there is a unique largest score, but raw scores may have different scales. They are not automatically log-odds. Exact score ties need a policy.

Imbalance: with 10 balanced classes, each binary task has 10% positive and 90% negative examples. Balanced multiclass data can produce imbalanced OvR tasks.

One-versus-one (OvO)

M(M − 1)/2 classifiers
Each pair votes; choose most votes.

Each classifier uses only the examples from its two classes. For M = 4, train 6 models; for M = 10, train 45. More classifiers does not automatically mean slower training than OvR, since each sees a smaller dataset.

Cycle example: A beats B, B beats C, C beats A. Each class receives one vote. The method needs a tie-breaker; pairwise preferences need not be globally consistent.

§17.3.7 and Figure 17.16. M notation, score-scale clarification, numeric examples, and cycle are explanatory additions. The book writes OvR scores as log-odds, which raw SVM scores do not generally represent.

§17.3.8 · pp. 593–594 / PDF pp. 623–624

Tune C and the kernel together.

K(x,z) = exp(−γ‖x − z‖²),   γ = 1/(2σ²)
Small C → stronger regularization   ·   Large C → stronger penalty on hinge loss

Large γ creates narrow similarities, so a point mainly influences nearby inputs; small γ creates broad similarities. C controls how strongly the model pays for margin violations relative to its weight norm. These parameters interact: a flexible narrow kernel can need more regularization. The book's small-γ/large-C and large-γ/small-C pattern is a useful intuition, not a law or guaranteed best setting.

  1. Choose a candidate grid across orders of magnitude. Murphy quotes C ∈ {2−5,2−3,…,215} and γ ∈ {2−15,2−13,…,23}.
  2. Within each CV training fold, fit preprocessing and the SVM; evaluate on that fold's validation data. Scaling changes distances and therefore the interpretation of γ.
  3. Compare joint (C, γ) validation results; refine a useful region if needed. Do not select by training accuracy.
  4. Refit using the selected settings. Report final performance on untouched test data or use nested CV when an unbiased selection-aware estimate is needed.

The lab uses an original, smaller powers-of-ten grid with real precomputed SVM fits. The lowest cell is the best on this small finite grid and these folds, not a universal setting. Its CV score has been used for selection, so it is not an untouched final test estimate.

Regularization paths: the end of §17.3.8 sketches following solutions as C changes. Support-vector membership can change along the path; you do not need that algorithm's derivation here. The paragraph's α = 1 and “no support vectors” claims do not match the standard dual variables used earlier; see the correction below.

§17.4 · p. 597 / PDF p. 627 · Eq. 17.118

Turn each training exemplar into a feature.

φ(x) = [K(x,x₁), …, K(x,xₙ)]T ∈ ℝN
f(x) = w₀ + ∑j=1N wⱼ K(x,xⱼ)
Binary logistic model: p(y=1|x,w) = σ(f(x))

This time the kernel values are explicit features fed into a parametric model such as logistic regression. With N training centers, there are N feature coefficients plus an optional intercept. Dense coefficients require all N centers for prediction; if only s coefficients are nonzero, only s centers need kernel evaluation. The kernel-evaluation cost per query falls from roughly N to s, apart from other computation.

Here K can be an arbitrary real similarity function: it need not be symmetric or PSD. You are constructing an explicit feature vector, not treating K itself as a feature-space inner product or a GP covariance. The resulting feature inner product φ(x)ᵀφ(z) is PSD even if the original similarity K is not.

Worked sparse prediction · original

Suppose φ(x) = (0.2, 1, 0.4), w = (0, 2, −1), and w₀ = −0.5. Then f = −0.5 + 0 + 2 − 0.4 = 1.1, so p ≈ 0.7503. Only the second and third centers contribute.

What “sparse” refers to

In these exemplar models, zero feature coefficients remove training centers. In SVMs, sparsity is in the dual coefficients. An SVM's primal vector w can still be dense. In either case, removing centers can speed prediction; sparsity alone guarantees neither better generalization nor well-calibrated uncertainty.

§17.4, Eq. 17.118. Intercept, arithmetic, PSD explanation, and the distinction between primal and exemplar sparsity are explanatory additions.

§17.4.1 · p. 598 / PDF p. 628

Three ways to regularize exemplars.

L2VM: an ℓ₂ penalty corresponds to a Gaussian prior in MAP estimation. It shrinks weights but usually leaves a dense expansion.

L1VM: an ℓ₁ penalty corresponds to a Laplace prior in MAP estimation. It can set coefficients exactly to zero, keeping a subset of the centers.

RVM: automatic relevance determination (ARD) uses a separate Gaussian prior precision for each coefficient and estimates those precisions by type II maximum likelihood / empirical Bayes.

wⱼ | αⱼ ∼ Normal(0, αⱼ−1)
Large αⱼ → strong shrinkage of weight j.

As a precision becomes very large, its weight is effectively forced to zero and the associated basis can be pruned. The retained kernel centers are called relevance vectors. These α values are prior precisions, not SVM dual multipliers.

The empirical-Bayes hyperparameter objective for an RVM is generally nonconvex, so optimization can depend on initialization and local optima. The name “relevance” does not mean a point is inherently important or an explanation of causality.

§17.4.1. The conditional Gaussian notation and precision interpretation unpack ARD; the section does not derive an RVM training algorithm.

§17.4.2 · pp. 598–601 / PDF pp. 628–631

Accuracy, cost, and uncertainty are separate.

In Figures 17.21–17.23, the methods have similar predictive behavior but different numbers of retained exemplars. The RVM is sparsest in these examples, followed by L1VM and then SVM in the regression comparison.

That is an empirical result for those examples, not a theorem that the RVM always wins. A sparser fit can predict faster, but the text also warns about overconfident predictions. Producing a probability distribution is distinct from demonstrating that it is calibrated.

For standard exact GP regression, prediction uses the training data; the mean typically needs N kernel evaluations. Full predictive variance can need O(N²) work with a stored dense Cholesky factor. The section's O(N) shorthand should not be read as the total cost of every GP prediction.

Reading carefully

Keep the equations; repair the shortcuts.

  1. Correct sign does not imply zero slack. At the start of §17.3.6, read the condition as m ≥ 1, rather than merely m > 0. The minimum slack is max(0,1−m). A correctly classified point with m = 0.4 still has slack 0.6.
  2. Unscaled logistic loss is not a pointwise upper bound on 0–1 loss. Contrary to the wording on p. 592, m = −0.1 gives log(1+e0.1) ≈ 0.744 < 1 for a wrong prediction. Hinge does upper-bound 0–1 loss. Logistic loss divided by log 2 does upper-bound it, because a wrong-sign margin has logistic loss at least log 2. Logistic remains a useful convex surrogate without the unscaled bound.
  3. The kink is the optimization issue. Hinge is differentiable away from m = 1. You can use subgradient and other nonsmooth optimization methods; “cannot use regular gradient methods” is too broad if taken to forbid gradient-based optimization entirely.
  4. Standard SVM multipliers satisfy 0 ≤ αᵢ ≤ C. They are not generally 1 inside the margin. A point strictly inside the margin normally has αᵢ = C; αᵢ/C is a normalized quantity with cap 1. Points at m = 1 can have intermediate multipliers. There is no general path endpoint at which all support vectors vanish: if all αᵢ = 0, w = ∑αᵢỹᵢφ(xᵢ) = 0, so a nonconstant two-class separator cannot remain. Treat p. 594's path paragraph cautiously.
  5. Probability models and PSD are different requirements. A covariance or SVM dot-product kernel needs PSD on every finite input set; an explicit exemplar feature function in Eq. 17.118 need not. The book's “positive definite” terminology includes PSD cases such as ordinary linear kernels.

Clarifications of pp. 591–594 and 597–601, checked by the displayed arithmetic and standard soft-margin constraints. No omitted SVM regression derivations are needed.
