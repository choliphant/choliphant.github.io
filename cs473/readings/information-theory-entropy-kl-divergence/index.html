Information Theory: Sections 6.1 & 6.2 Review

Comprehensive overview of discrete entropy, relative entropy (KL divergence), and an interactive quiz.

6.1 Entropy

Entropy quantifies the average uncertainty or lack of predictability associated with a random variable.

6.1.1 Discrete Entropy

For a discrete random variable X over K states with distribution p:

H(X) = - ∑k=1K p(X = k) log2 p(X = k) = -EX[log2 p(X)]
  • Units: Measured in bits when using base 2, or nats when using the natural logarithm.
  • Extremes: Minimal entropy (0 bits) occurs at deterministic delta distributions. Maximal entropy occurs at a uniform distribution: Hmax = log2(K).
  • Binary Entropy: For X ∈ {0, 1} with parameter θ = p(X=1): H(θ) = -[θ log2 θ + (1-θ) log2(1-θ)], peaking at 1 bit when θ = 0.5.

6.1.2 Cross Entropy

Expected bits needed to code samples drawn from true distribution p using an encoding distribution q:

Hce(p, q) = - ∑k=1K pk log qk

By Shannon's source coding theorem, this is minimized when q = p, where Hce(p, p) = H(p).

6.1.3 & 6.1.4 Joint and Conditional Entropy

H(X, Y) = - ∑x,y p(x, y) log2 p(x, y)
H(Y | X) = ∑x p(x) H(p(Y | X=x)) = H(X, Y) - H(X)
Conditioning Never Increases Entropy (On Average): H(Y | X) ≤ H(Y), with equality if and only if X and Y are independent. While a single specific observation might increase entropy, uncertainty decreases on average.

6.1.5 Perplexity

Defined as 2H(p) (or 2Hce(pD, p) when evaluating empirical data). It measures the effective weighted branching factor of a sequence or language model. Lower perplexity indicates superior predictive capability.

6.2 Relative Entropy (KL Divergence)

Kullback-Leibler divergence measures the statistical distance from distribution q to reference distribution p.

6.2.1 – 6.2.4 Definition, Bounds, & Properties

DKL(p || q) = ∑k=1K pk log (pk / qk) = Hce(p, q) - H(p)
  • Information Penalty: Represents the excess expected bit-rate when using code q instead of optimal code p.
  • Information Inequality: DKL(p || q) ≥ 0 for all p, q, with equality if and only if p = q (proven via Jensen's inequality).
  • Not a Metric: KL divergence is strictly asymmetric (DKL(p || q) ≠ DKL(q || p)) and does not satisfy the triangle inequality.

6.2.5 KL Divergence and Maximum Likelihood Estimation (MLE)

Minimizing forward KL divergence between the empirical distribution pD and a parametric model qθ is mathematically equivalent to maximizing the log-likelihood of the observations:

arg minθ DKL(pD || qθ) = arg minθ - (1/N) ∑n=1N log qθ(xn)

6.2.6 Forward vs. Reverse KL

When approximating a complex/multimodal target distribution p with a simpler distribution q (e.g., unimodal Gaussian), the direction chosen leads to radically different behaviors:

Forward KL: DKL(p || q)

Name: Inclusive KL / Moment Projection (M-projection)

Objective: ∫ p(x) log (p(x)/q(x)) dx

Mechanism: If p(x) > 0, we cannot let q(x) → 0, or the penalty diverges to infinity.

Behavior: Zero-avoiding / Mean-covering. Forces q to spread its mass over all regions where p has support, often overestimating variance and averaging across multiple modes.

Reverse KL: DKL(q || p)

Name: Exclusive KL / Information Projection (I-projection)

Objective: ∫ q(x) log (q(x)/p(x)) dx

Mechanism: If p(x) ≈ 0, q(x) must also be driven to 0 to avoid large penalties.

Behavior: Zero-forcing / Mode-seeking. Forces q to concentrate mass strictly where p has probability, locking tightly onto a single dominant mode while ignoring others (common in Variational Inference).
