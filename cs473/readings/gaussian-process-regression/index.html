§17.2 introduction · printed p. 574

A Gaussian distribution over function values.

A Gaussian process (GP) is a distribution over functions f. Choose any finite set of inputs. Their function values are jointly Gaussian. The inputs themselves do not have to be Gaussian, and the function does not have to be a bell-shaped curve.

f ∼ GP(m, K)
E[f(x)] = m(x),   Cov[f(x), f(x′)] = K(x, x′)

The mean function m describes the prior trend. The covariance kernel K describes how deviations from that trend are related. High covariance lets an observed value inform another value. We condition a joint Gaussian to turn those relationships into predictions.

A kernel for the experiments

K(x, x′) = sf² exp(−‖x − x′‖² / (2ℓ²))
Squared exponential / RBF kernel. ℓ > 0 is the length scale; sf² is the prior signal variance.

Short ℓ makes correlation decay quickly with distance; long ℓ makes distant values more connected. Since K(x,x) = sf², sf controls the prior vertical spread. The GP kernel is a covariance function: it must produce symmetric positive semidefinite Gram matrices. It is not required to integrate to one like a density kernel.

A zero mean prior says E[f(x)] = 0 before observing data. It does not say every sampled function, or the posterior mean, is zero. With an RBF kernel, predictions far from the data return toward the chosen prior mean and prior variance.

Every block has a job and a shape.

Use N training inputs, M test inputs (the textbook’s N∗), and D features per input. Rows are examples. In this companion, vectors are column vectors; posterior quantities carry a “post” label to distinguish them from prior means.

17.2.1 · Noise-free observations

When y is the function itself.

Assume yn = f(xn). The observed training function values and unknown test function values share a joint Gaussian prior:

[fX; f∗] ∼ N([mX; m∗], [[K, B], [BT, C]])
Semicolon stacks vectors vertically; the nested brackets are a 2 × 2 block matrix. Here fX = y.

Condition on the known fX. The Gaussian conditioning rule gives:

f∗ | D, X∗ ∼ N(μpost, Σpost)
μpost = m∗ + BTK−1(y − mX)
Σpost = C − BTK−1B
  1. Compute residualsSubtract the prior training mean: y − mX. This is what the observations teach us beyond the prior.
  2. Adjust the meanThe covariance blocks transfer those residuals from training locations to test locations.
  3. Reduce uncertaintySubtract the information supplied by training values from the prior test covariance C.

Why this interpolates

Set the whole test set equal to X, so B = C = K. When K is invertible:

μpost(X) = mX + K K−1(y − mX) = y
Σpost(X) = K − K K−1K = 0

Exact data pins the function at every training point: the mean equals the observed value, and latent variance there is zero. Between those locations, many functions can still agree with the data.

The inverse formulas assume K is nonsingular. Repeated inputs can make it singular. Two different exact outputs at the same input are inconsistent with a single noise-free function. Numerical stabilization does not make that model assumption true.

17.2.2 · Noisy observations

When y is an imperfect measurement.

Now yn = f(xn) + εn, with independent εn ∼ N(0, σy²), independent of f. The outputs include a smooth signal and independent measurement noise.

Cov[yi, yj] = K(xi, xj) + σy²δij
A = K + σy² IN,   δij = 1 if i = j, else 0.

Each measurement contributes extra variance to its own diagonal entry. Independent noise contributes no off-diagonal covariance. Even two observations taken at the same input have independent errors under this model; δ refers to observation indices, not equality of input locations.

The prediction target is still the latent function f∗. The joint covariance blocks are [[A, B], [BT, C]]. Neither the train-to-test block B nor the latent test block C acquires measurement noise.

μpost = m∗ + BTA−1(y − mX)
Σpost = C − BTA−1B

These are the same conditioning equations with A in place of K. The posterior usually smooths the observed values instead of passing through all of them. Positive σy² also makes A positive definite when K is positive semidefinite, in exact arithmetic.

One test input

k∗ = [K(x1,x∗), …, K(xN,x∗)]T,   k∗∗ = K(x∗,x∗)
μpost = m(x∗) + k∗TA−1(y − mX)
vf = k∗∗ − k∗TA−1k∗

With zero prior mean, define α = A−1y once and predict μpost(x∗) = ∑n K(x∗,xn)αn. The coefficients α need not be positive or sum to one. The book notes that this mean matches kernel ridge regression; the GP also supplies a posterior covariance.

Original worked examples

One observation makes every term visible.

Let X = [0], y = [2], m(x) = 0 and K(0,0) = K(x∗,x∗) = 1. Choose a test point with K(0,x∗) = 0.5. Then K = [1], B = [0.5], C = [1].

Exact (σy = 0)Noisy (σy = 0.5)
Training covariance A11 + 0.5² = 1.25
α = A−1y22/1.25 = 1.6
Posterior mean0.5 × 2 = 10.5 × 1.6 = 0.8
Latent variance1 − 0.5²/1 = 0.751 − 0.5²/1.25 = 0.8
Latent standard deviation√0.75 ≈ 0.866√0.8 ≈ 0.894

At the training input, the cross-covariance is 1 instead of 0.5. Exact observations give mean 2 and variance 0. The noisy model gives mean 2/1.25 = 1.6 and latent variance 1 − 1/1.25 = 0.2. Knowing a noisy measurement does not reveal the latent function exactly.

A two-observation calculation

For a valid synthetic covariance example, take K = [[1, 0.5], [0.5, 1]], k∗ = [0.75, 0.75]T, k∗∗ = 1, y = [1, −1]T, zero mean and no noise.

K−1 = (1/0.75) [[1, −0.5], [−0.5, 1]]
α = [2, −2]T;   μpost = 0.75(2) + 0.75(−2) = 0
K−1k∗ = [0.5, 0.5]T
vf = 1 − [0.75, 0.75][0.5, 0.5]T = 0.25

The opposite outputs cancel in the mean, but uncertainty is still reduced. A zero predicted mean does not mean the model learned nothing. This synthetic Gram matrix illustrates conditioning; it is not the RBF data set used in the matrix experiment.

Implementation extension

Function or future measurement?

Equations 17.34–17.37 predict f∗. For a new independent noisy observation y∗ = f∗ + ε∗, add its noise variance after conditioning:

E[y∗ | D] = μpost
Cov[y∗ | D] = Σpost + σy² IM

In the one-point noisy example, vf = 0.8 but vy = 0.8 + 0.25 = 1.05. At the training input, the variance of a new noisy replicate is 0.2 + 0.25 = 0.45. This is different from asking about an already observed y, whose value is known.

Plot bands as μ ± 2√v. The square root matters: variance is in squared output units. For an individual Gaussian marginal, this covers about 95.45% posterior probability. It is not a guarantee that an entire sampled curve stays inside the band.

Derived from the independent-noise model in §17.2.2. The latent/measurement distinction extends the assigned equations. Fig. 17.7 uses mean ± 2 standard deviations.

What the covariance tells you

Uncertainty depends on locations.

With the kernel and σy fixed, Σpost depends on X and X∗, not on the observed values y. Changing y changes the mean. It does not change the covariance in these equations.

The diagonal entries are the marginal variances at test inputs. Off-diagonal entries describe remaining dependence between their function values. Use the full covariance to draw coherent joint function samples; independent draws from each marginal lose that dependence.

Conditioning subtracts a positive semidefinite matrix from C. Thus each latent marginal variance is no larger than its prior variance. With an RBF kernel, as all train-to-test covariances approach zero, μpost approaches m∗ and Σpost approaches C.

These statements hold for fixed hyperparameters. If you refit the kernel or noise using the observed outputs, changing y can change those fitted settings and therefore change the covariance indirectly.

Lab preparation · implementation extension

Translate the equations into operations.

This is a map for your own implementation, not a completed lab solution. No lab notebook requirements beyond the supplied reading goal are assumed.

  1. Define the model. Choose or receive m, K and the observation noise standard deviation σy. Keep signal variance sf² and noise variance σy² distinct.
  2. Build the blocks. Evaluate K on all training pairs, B on all train/test pairs, and C on all test pairs. Subtract m(X) from y.
  3. Build A. Use A = K for exact observations or A = K + σy²I for noisy ones. Add noise once to each training diagonal entry.
  4. Solve for α. Solve Aα = y − m(X). Reuse that result to compute μpost = m(X∗) + BTα.
  5. Solve for covariance reduction. Solve AV = B, then compute Σpost = C − BTV. V has shape N × M.
  6. Choose the output. Return the full covariance or its diagonal, as your lab asks. For new noisy measurements, add σy²I. Take square roots only when computing standard deviations or plotting bands.

Use solves rather than explicitly constructing A−1. For symmetric positive definite A, a Cholesky factorization A = LLT can be reused for both solves. Equivalently, if W solves LW = B, then Σpost = C − WTW. This numerical advice supports implementation; the full §17.2.5 is outside the assigned scope.

A tiny diagonal “jitter” can stabilize a numerical factorization, but is distinct from modeled measurement noise. Any nonzero jitter perturbs exact interpolation. Tiny negative variances at floating point scale may be roundoff; substantially negative values call for checking shapes, solves and the kernel, not silently hiding the error.

Keep these straight

Seven mistakes worth catching.

MistakeRepair
“A GP assumes the inputs are Gaussian.”It assumes finite collections of function values are jointly Gaussian.
Adding σy to the diagonalAdd the variance σy² if your input parameter is a standard deviation.
Adding noise to every matrix entryIndependent measurement noise contributes only σy²I to A.
Expecting noisy training values to be interpolatedExact interpolation belongs to the noise-free model under the stated invertibility assumption.
Forgetting the nonzero meanCenter training values by m(X), then add m(X∗) to the prediction.
Plotting μ ± 2vUse μ ± 2√v; label whether v is latent or measurement variance.
Treating Σ as just a list of variancesIts off-diagonal entries couple the predictions at different test inputs.
