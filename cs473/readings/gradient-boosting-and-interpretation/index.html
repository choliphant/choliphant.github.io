§18.5.5 · pp. 616–618 / PDF pp. 646–648

A weak learner approximates a descent direction.

Boosting builds an additive predictor fM(x) = f0(x) + ∑m=1M νFm(x). Earlier stages stay fixed while a new function Fm is added. The generic recipe works with a chosen loss ℓ(y,f), rather than deriving an entirely new algorithm for each loss.

On N training inputs, represent the current function by the vector (f(x₁), …, f(xN)). A derivative with respect to each predicted score says how its loss changes. It is not a derivative with respect to the input x, and does not require differentiating the hard split thresholds of a tree.

gim = [∂ℓ(yi,s)/∂s]s=fₘ₋₁(xᵢ) · Eq. 18.38
rim = −gim · negative gradient / pseudo-residual
Fm = argminF in weak-learner family ∑i (rim − F(xi))² · Eq. 18.41
fm(x) = fm−1(x) + νFm(x),   0 < ν ≤ 1 · Algorithm 18.3
  1. Start with a simple predictor. Use a loss-minimizing constant: for half squared error, the mean; for absolute error, a median. For binary log-loss with a full logit score, log[p̄/(1−p̄)] when 0 < p̄ < 1.
  2. Compute a target at every training input. Pseudo-residuals tell us which direction each current prediction should move.
  3. Fit a regression learner to those targets. A function learned from (xi,rim) can be evaluated on new inputs. A raw vector of N updates alone cannot.
  4. Add a shrunken correction. Repeat, recomputing pseudo-residuals using the updated ensemble.

The book first describes direct function-vector descent fm = fm−1 − βmgm, with line search for βm (Eqs. 18.39–18.40). Algorithm 18.3 fits a function to −g and uses ν instead. The plus sign in the additive update is correct because the fitted targets already include the negative sign.

Initialization clarification: Algorithm 18.3 writes an argmin over F without stating its family. If F were unrestricted, it could memorize the training targets before boosting started. The usual useful initialization is a constant, which is the convention used here.

§18.5.5.1 · pp. 618–619 / PDF pp. 648–649

Choose the regions using gradients; choose leaf values using the loss.

A regression tree writes its correction as Fm(x) = ∑j=1Jₘ wjmI(x ∈ Rjm) (Eq. 18.44). The regions partition the input space. Several stages produce an additive collection of piecewise constant corrections.

  1. Fit a regression tree to the pseudo-residuals. This chooses regions Rjm that make the descent signal predictable from x.
  2. Keeping those regions fixed, optionally refit each leaf's update against the original loss.
  3. Apply shrinkage to the resulting update when adding it to the current ensemble.
ŵjm = argminw ∑i:xᵢ∈Rⱼₘ ℓ(yi, fm−1(xi) + w) · Eq. 18.45
Then fm(x) = fm−1(x) + ν ∑j ŵjmI(x ∈ Rjm)

Squared error

With ei = yi−fm−1(xi), minimizing ∑½(ei−w)² gives mean(e) in the leaf. Since r = e, this is already the regression tree's fitted residual mean.

Original leaf: e = {1,2,9}. The update is 4. With ν = .1, the actual addition is .4, not 4.

Absolute error

Minimizing ∑|ei−w| gives a median(e). For {1,2,9}, a median is 2, while the mean of gradient targets {1,1,1} is 1. Fitting signs and refitting original-loss leaf values are different steps.

With ν = .1, the median-refitted addition is .2. For an even count, any value between the middle two residuals minimizes the leaf loss; the lab uses their midpoint.

Algorithm 18.3's basic gradient fit can use just the fitted gradient means; §18.5.5.1 describes the additional original-loss leaf optimization. Do not silently treat a sign average as an absolute-loss-optimal response update.

§18.5.5 · p. 618 / PDF p. 648

Classification still fits regression targets.

For binary log-loss, gradient boosting can fit any suitable regression learner to the negative-gradient vector; unlike LogitBoost, the basic method does not require a weighted least-squares fitting interface. The original labels are categorical, but a target such as 1−.8 = .2 is a real number.

For C classes, compute ric = I(yi=c)−πic, fit C class-specific regression trees, update their class scores, and combine the scores with softmax:

πic = exp(sc(xi)) / ∑c′ exp(sc′(xi)) · Eq. 18.43

The fits can be separate, but their probabilities are coupled through the denominator. The targets across classes sum to zero for each case. For true class 2 and π = {.2,.5,.3}, the vector is {−.2,.5,−.3}. Do not train these trees as ordinary hard-label classifiers or normalize their raw tree outputs as if they were nonnegative probabilities.

Shrinkage

A smaller ν makes each correction smaller. It usually needs more stages M and can regularize the final fit. Learning rate, tree complexity, and stage count interact; select them using validation. More stages need not improve validation performance indefinitely.

Stochastic gradient boosting

At each stage, draw a random fraction of cases without replacement to fit that stage's learner. A new sample is drawn at later stages. This can reduce computation and regularize. It is not the same as feature subsampling or bootstrap sampling with replacement.

§18.5.5, Algorithm 18.3, Eqs. 18.42–18.43. Full-logit binary convention and validation remarks are clarifications.

§18.5.5.2 · pp. 619–620 / PDF pp. 649–650

XGBoost uses curvature and penalizes the next tree.

The section describes a regularized second-order tree-boosting objective. At stage m, evaluate gi = ∂ℓ/∂s and hi = ∂²ℓ/∂s² at the current ensemble predictions, then approximate the effect of adding the next tree. g is the positive derivative here; the minus sign will enter the optimal leaf weight.

ℓ(yi,si+F(xi)) ≈ ℓ(yi,si) + giF(xi) + ½hiF(xi)² · Eqs. 18.49–18.50
Ω(F) = γJ + ½λ∑j=1Jwj²,   γ, λ ≥ 0 · Eq. 18.47

J is the number of leaves; γ charges for an additional leaf and λ shrinks leaf weights. For an additive ensemble, the stage objective includes the new tree's penalty plus constants from previous stages. A clear overall form is ∑iℓ(yi,fM(xi)) + ∑mΩ(Fm). This makes the tree-wise role of the book's Ω notation explicit.

For a fixed tree structure q, let Ij be the cases assigned to leaf j. Summing their derivatives gives Gj = ∑i∈Iⱼgi and Hj = ∑i∈Iⱼhi. Drop terms independent of the new tree:

L̃(q,w) = ∑j [Gjwj + ½(Hj+λ)wj²] + γJ · Eq. 18.53
∂L̃/∂wj = Gj + (Hj+λ)wj = 0
w*j = −Gj/(Hj+λ) · Eq. 18.54
L̃(q,w*) = −½∑jGj²/(Hj+λ) + γJ · Eq. 18.55

Assume positive denominators Hj+λ. With convex losses, hi ≥ 0; λ > 0 protects a zero-curvature leaf. For half squared error, g = s−y and h = 1, so w* = ∑(y−s)/(Nj+λ). At λ = 0, this is the ordinary residual mean. For full-logit binary loss, g = p−y and h = p(1−p).

The Taylor expression is exact for a quadratic loss, approximate for log-loss. These formulas describe the simplified textbook objective, not every constraint or parameter in a software implementation. The book also discusses feature subsampling at internal nodes and engineering for scalable computation; feature sampling is separate from the case sampling in stochastic boosting.

§18.5.5.2 · p. 620 / PDF p. 650

Split only when two leaves beat their parent.

Gain = ½[GL²/(HL+λ) + GR²/(HR+λ)
− (GL+GR)²/(HL+HR+λ)] − γ · Eq. 18.56

This is parent optimized objective minus children optimized objective. One parent leaf becomes two child leaves, so the penalty difference is γ, not 2γ. Each child gets its own λ in its denominator; the parent has only one λ.

Original worked example: GL = −4, HL = 2, GR = 2, HR = 2, λ = 1. The unsplit weight is 2/5 = .4. Split weights are 4/3 and −2/3. The unpenalized improvement is ½(16/3 + 4/3 − 4/5) = 44/15 ≈ 2.9333. At γ = .5, gain = 73/30 ≈ 2.4333, so the simplified criterion favors the split. At γ = 3, gain = −1/15, so it rejects it.

These numbers arise from half squared-error residuals {2,2,−1,−1} with two cases per child. The negative GL produces a positive left correction. Greedy search compares valid candidate splits; positive gain alone does not mean a split is globally optimal or improves held-out performance. At exactly zero gain, the lab keeps the simpler parent.

§18.5.5.2, Eq. 18.56. Worked numbers and tie policy are original. The lab evaluates the raw textbook surrogate before any optional learning-rate scaling.

§18.6–18.6.1 · pp. 620–622 / PDF pp. 650–652

Importance adds up split improvements.

A single small tree can be read as rules. A large ensemble is harder to inspect, so the book aggregates the gains of splits that use each feature. Here Gj denotes node gain; this reuses the symbol G from the previous section, where it denoted a sum of gradients.

Rk(T) = ∑j internal Gainj I(vj=k) · Eq. 18.57
Rk = (1/M)∑m=1M Rk(Tm) · Eq. 18.58
Relative importancek = 100 Rk/maxlRl,   if max R > 0

For a binary tree with J leaves, there are J−1 internal nodes; leaves do not contribute split gains. Use a consistent gain scale for every node, such as reductions in the same total loss, or globally weighted impurity decrease. Summing unweighted local impurity drops across differently sized nodes can distort their contribution.

Original calculation: tree 1 has gains (feature A: 6, feature B: 2); tree 2 has gains (A: 2, C: 2). Their mean scores are (A: 4, B: 1, C: 1). Scaling the largest score to 100 gives (100,25,25). These values sum to 150, not 100. A different normalization to sum 100 would give (66⅔,16⅔,16⅔).

What the number cannot tell you · interpretation caveats

  • No direction: a feature may matter because of high values, low values, or interactions. Importance alone does not say “increasing it increases the prediction.”
  • No causality: predictive association and split usage do not identify the effect of changing the real-world feature.
  • No uniqueness: correlated or duplicate features may share or substitute for one another; a low score does not prove no useful information exists in a feature.
  • Possible selection bias: features with many possible splits can receive inflated training-based importance. These are model summaries, not unbiased measures of scientific relevance.

The book's digit example highlights image locations useful for distinguishing 0 from 8; its spam example highlights words and characters useful to the fitted classifier. Those rankings are specific to the task, data, and model. If all gains are zero, max normalization is undefined; report that there is no positive gain rather than divide by zero.

§18.6.2 · pp. 622–623 / PDF pp. 652–653

Partial dependence replaces a feature, predicts, then averages.

Choose a grid value z for feature k. In a reference dataset, replace feature k by z in every row, leave each row's other coordinates intact, predict with the fixed ensemble, and average. Repeat at other z values. This describes the model; it does not retrain it.

PDk(z) = (1/N)∑n=1N f(xn,−k, z) · Eq. 18.59
PDjk(u,z) = (1/N)∑n=1N f(xn,−jk, u,z) · Eq. 18.60

Replacing two features produces a surface that can reveal interactions. In the book's spam illustration, the change associated with more exclamation marks depends on whether “hp” is present. Tick marks along the plot mark empirical deciles and help show where observed feature values lie.

Original two-stump ensemble

Let a,b ∈ {0,1} and let the ensemble's logit score be s(a,b) = −1 + 2a + b. It is an intercept plus two stumps. For reference rows with b = {0,1}, the score predictions at a = 0 are {−1,0}, giving score PD = −.5; at a = 1 they are {1,2}, giving 1.5.

Mean probability at a=0: [σ(−1)+σ(0)]/2 ≈ .3845
Mean probability at a=1: [σ(1)+σ(2)]/2 ≈ .8059
σ(mean score) at a=0: σ(−.5) ≈ .3775 ≠ .3845

Choose the plotted quantity explicitly. For a classifier, averaging probabilities, averaging logits, and taking the logit of an average probability are different operations. The book discusses log-odds plots; the lab shows these alternatives separately. For p strictly between 0 and 1, logit(p) = log[p/(1−p)].

A marginal model summary is not a conditional or causal effect. PD averages over the reference distribution of the other features, not their distribution conditional on k=z. If features are strongly correlated, replacement can create combinations absent from the observed data. If reference rows satisfy a=b, evaluating a=0 with b=1 creates an unsupported combination. The model still returns a value, but the data do not directly support that contrast.

Averaging can hide heterogeneous effects. For s(a,b)=−1+2a+b−4ab, increasing a raises the score by 2 when b=0 but lowers it by 2 when b=1. With an equal mixture of b values, mean score PD is flat at −.5 even though each group's prediction changes substantially. A two-feature surface or per-row curves reveal what the average hides.

Common mistakes

Keep the signs, units, and questions straight.

  • Subtracting twice: fit r=−g, then add the fitted correction. In XGBoost, G sums positive derivatives and w*=−G/(H+λ).
  • Calling every target y−f: that identity holds for half squared error. Absolute loss uses signs; log-loss uses probability errors on a specified score scale.
  • Equating a gradient mean with a leaf optimum: absolute-loss leaf refitting uses residual medians, not the mean of signs.
  • Forgetting the extra leaf: parent-to-two-children split gain pays one additional γ. Shrinkage ν and weight penalty λ play different roles.
  • Mixing gain symbols: XGBoost G is a sum of derivatives; importance uses gain in the objective. Neither is necessarily classification accuracy improvement.
  • Reading relative importance as a probability: “100” means largest under the book's normalization, not “100% of all predictive information.”
  • Interpreting PD as p(y|xk) from the population: it averages a model over replacement rows. Conditional dependence and causal effects require different arguments.
  • Changing the output scale halfway through: averaging logits, then applying σ, generally differs from averaging probabilities.

02 / Fit regions, then choose leaf corrections · §18.5.5.1

Boost six cases, one stump at a time.

Ordered inputs x={1,2,3,4,5,6} have responses y={0,1,1,3,3,v}. Each round searches all five nonempty midpoint splits by squared error on the negative-gradient targets. Exact ties use the leftmost threshold. Only the last response v changes.

Initial constant: response mean for squared error, midpoint median for absolute error. A zero residual has sign 0. No line search, validation, stochastic sampling, or depth beyond a stump is used. Numerical convention: absolute-loss residuals within 10⁻¹⁰ of zero use sign 0; split-cost differences within 10⁻¹² count as ties.

05 / Replace, predict, average · §18.6.2
