Orientation · §20.1 introduction, p. 657 / PDF p. 687

One basis, two directions of travel.

Each input x has D features. PCA keeps L orthonormal directions in W, with L ≤ D. Fit a training mean μ, subtract it before projection, and add it back after reconstruction. This makes the fitted subspace pass through the training mean, rather than forcing it through the origin.

Column-vector encoding: z = Wᵀ(x−μ)   ∈ ℝL
Decoding: x̂ = μ + Wz = μ + WWᵀ(x−μ)   ∈ ℝD
WᵀW = IL;   WWᵀ is a D × D projection, generally not ID.
QuantityShapeMeaning
XcN × DCentered data; one example per row.
C = XcᵀXc/ND × DCovariance under the book's 1/N convention.
W = [w₁,…,wL]D × LTop covariance eigenvectors / loading directions.
Z = XcWN × LPC scores, the coordinates of the examples.
X̂c = ZWᵀN × DReconstruction in centered coordinates.

Use the learned training mean and basis to transform a new point. If scaling is part of preprocessing, learn its scales from training data too. Refitting them on held-out data changes the representation and leaks information across the split.

Notation from the §20.1 introduction, Eqs. 20.1–20.2, and assigned Eqs. 20.23–20.25. These are operational formulas, not the skipped §20.1.2 derivation. Train-only preprocessing is a practical reminder.

§20.1.1 · pp. 657–659 / PDF pp. 687–689

A coordinate can summarize thousands of pixels.

2D → 1D: Figure 20.1 projects points to a line through the mean. The score is a signed location along that line. The reconstruction lies on the line; the discarded displacement is perpendicular to it.

Digit images: Figure 20.2 represents 28 × 28 MNIST images of the digit 9 as 784-feature vectors, then gives each image just two scores. Correlated pixels make a compact approximation possible. In that example, the first direction appears to capture orientation and the second stroke thickness. Those are interpretations of this fitted dataset, not guaranteed meanings of “PC1” and “PC2” for other data.

Eigenfaces: Figure 20.3 uses 64 × 64 Olivetti face images, so D = 4096. A loading vector can be reshaped into a 64 × 64 image. The mean face is separate; a reconstruction is the mean plus a weighted sum of these signed basis images. The illustrated directions reflect lighting and eyebrow-region variation. Compact scores can be used as inputs to a nearest-neighbor classifier; this does not make PCA a supervised procedure or guarantee improved classification on every dataset.

Original tiny “image” example:
μ = (10,10),   w₁ = (1,1)/√2,   x = (13,11)
z₁ = [(13−10)+(11−10)]/√2 = 2√2
x̂ = (10,10) + 2√2(1,1)/√2 = (12,12)
‖x−x̂‖² = 1²+(−1)² = 2

Changing w₁ to −w₁ also changes z₁ to −z₁, leaving x̂ unchanged. With equal eigenvalues, the axes inside the tied eigenspace can rotate; even the displayed loading directions may not be unique. Compare subspaces and reconstructions rather than demanding identical signed eigenvectors from different computations.

§20.1.3.1 · p. 662 / PDF p. 692

Units change the question PCA answers.

Centering removes a feature's mean. Standardization also divides it by its standard deviation. Raw covariance PCA favors directions with large numerical variance; changing a measurement from meters to centimeters can change its first component even though the underlying observations are the same.

A = diag(a₁,…,aD),   ad = √Cdd
Xs = XcA⁻¹
R = XsᵀXs/N = A⁻¹CA⁻¹
R is the correlation matrix when all feature variances are positive and the same variance convention is used.
Standardized PCA: Z = XsWs
Return to original units: X̂ = 1μᵀ + ZWsᵀA

The height/weight example in Figure 20.5 shows why correlation PCA is often sensible when features have different units. The book recommends it here. It is a modeling choice: if absolute variance in common units is meaningful, covariance PCA may be the right objective. Standardization gives a low-variance noise feature the same unit marginal variance as any other feature.

Original units example

For C = [[4,1.2],[1.2,1]], standard deviations are (2,1), giving R = [[1,.6],[.6,1]]. Raw PCA's first loading is approximately (.944,.331), with eigenvalue 4.421. Standardized PCA uses (1,1)/√2 with eigenvalue 1.6. If the second feature's numerical units are multiplied by 10, raw C becomes [[4,12],[12,100]] and the first raw loading points mostly along feature 2. The correlation matrix remains unchanged.

  • Raw PCA minimizes Euclidean reconstruction error in the chosen input units; standardized PCA minimizes it in standardized units.
  • A loading in standardized coordinates must be mapped back before interpreting a reconstruction direction in original units. The feature axes are no longer weighted equally there.
  • A constant feature has zero standard deviation. Drop it or handle it explicitly; never divide by zero.

§20.1.3.2 · p. 663 / PDF p. 693

When D is huge, diagonalize the smaller matrix.

Let X mean the centered N × D data matrix for this card. Forming XᵀX requires a D × D matrix. If D > N, use the N × N Gram matrix K = XXᵀ instead. Their nonzero eigenvalues match because these two products share the same squared singular values.

Kuj = αjuj,   ‖uj‖ = 1,   αj > 0
vj = Xᵀuj/√αj   · Eq. 20.22, one component
W = XᵀULdiag(α₁,…,αL)−1/2
λj(C) = αj/N,   Z = XW

Why the divisor matters: ‖Xᵀuj‖² = αj, so merely using Xᵀuj gives the correct direction at the wrong length. Only use positive eigenvalues in this mapping. Centering implies rank(X) ≤ min(N−1,D), so at least one Gram eigenvalue is zero when N > 0.

Keep the normalization consistent. Here α refers to unnormalized XXᵀ, while λ refers to C = XᵀX/N. If you diagonalize XXᵀ/N instead, the normalized feature vector is Xᵀu/√(Nλ). Do not substitute a covariance eigenvalue into √α without its N factor.

For N = 100 and D = 10,000, the covariance has 100 million entries; the Gram matrix has 10,000. At eight bytes per entry, those matrices alone occupy about 800 MB versus 80 kB. The data, factorization workspace, and recovered D × L basis still cost memory. Gram PCA avoids the large covariance; it does not eliminate all high-dimensional computation.

§20.1.3.3 · p. 663 / PDF p. 693

SVD gives the loadings and scores directly.

For centered X, write the compact SVD as X = USVᵀ. Retain the L largest singular values s₁ ≥ … ≥ sL and their left/right singular vectors. Use L at most the positive rank when you want informative components.

X ≈ ULSLVLᵀ
W = VL   · D × L; right singular vectors are the loading directions
λj(C) = sj²/N
Z = XVL = ULSL   · Eq. 20.23; scores are not U alone
X̂c = ZVLᵀ = ULSLVLᵀ   · Eq. 20.24

Original exact 3 × 4 example

Take centered rows (3,1,0,0), (−1,−3,0,0), (−2,2,0,0). The nonzero singular values are 2√3 and 4, ordered as 4 then 2√3. Thus the covariance eigenvalues are 16/3 and 4. The first feature-space loading is (1,1,0,0)/√2; its scores are (2√2,−2√2,0). Keeping it leaves per-case squared reconstruction error 4, the discarded covariance eigenvalue. The matrix lab walks through every product.

Text correction: the sentence on p. 663 says the weights are the top L “eigenvalues,” then sets W = UΣ. It must mean eigenvectors: W contains directions; eigenvalues are scalar variances.

Direct SVD is often computationally preferable and avoids explicitly forming XᵀX. As an implementation note, forming that product squares the nonzero singular-value condition number and can reduce numerical accuracy. Truncated or randomized methods target only a small leading subspace; randomized approximations need not reproduce the exact result.

The book contrasts exact and randomized SVD costs. Treat its randomized O(NL²)+O(L³) expression as schematic, not a full cost for arbitrary dense N × D input: processing X must also depend on D. Actual work depends on matrix shape, sparsity, requested rank, oversampling, and power iterations. No runtime claims or current software defaults are needed for the algebra here.

§20.1.4.1 · p. 664 / PDF p. 694

Extra axes can only reduce orthogonal reconstruction error.

ℒL(𝒟) = (1/|𝒟|)∑n∈𝒟 ‖xn−x̂n‖²   · Eq. 20.25
zn = WLᵀ(xn−μ),   x̂n = μ + WLzn

Fit μ and a single ordered PCA basis on the training data, then compare its nested first-L subspaces. When you add orthonormal direction wL+1, each point's error decreases by [wL+1ᵀ(x−μ)]². This holds for any input point, including a held-out point. Consequently, both train and held-out reconstruction curves are nonincreasing in this setting.

At L = rank(Xtrain,c), training reconstruction is exact. Held-out reconstruction need not be zero there: new points can have components outside the training span. At L = D with a full orthonormal basis, any input reconstructs exactly. Those zero-eigenvalue directions are not learned signal, but completing the basis can still reduce held-out geometric error.

Why no U shape? The book's MNIST plots show test reconstruction improving with L. Reconstruction error alone rewards every extra axis; ordinary PCA supplies no normalized data density that balances fitting and uncertainty. This criterion therefore does not choose a “true” latent dimension by a held-out minimum. It also says nothing about whether a discarded small-variance feature predicts a target.

Squared loss versus RMSE: Eq. 20.25 is mean squared vector distance. Figure 20.6 labels its vertical axis RMSE. The square root is a different scale, though it preserves monotonicity. Per-feature MSE further divides Eq. 20.25 by D; always state your normalization.

If the goal is prediction, choose L using a task-specific validation criterion inside the preprocessing/training pipeline. For denoising, minimizing error to the noisy observation can favor retaining noise; a clean-target or suitable noise-aware criterion answers a different question. These are practical extensions, not additional assigned algorithms.

§20.1.4.2 · pp. 664–665 / PDF pp. 694–695

A scree plot and explained variance read the same spectrum.

Sort covariance eigenvalues λ₁ ≥ … ≥ λD ≥ 0. A scree plot shows λj against component index j. A sharp drop followed by a flatter tail suggests an elbow, but a spectrum need not have one.

Training ℒL = ∑j=L+1D λj   · Eq. 20.26, C = XcᵀXc/N
FL = (∑j=1L λj)/(∑j=1Lmax λj)   · Eq. 20.27

For the total explained variance, the denominator includes the complete spectrum, or all positive-rank eigenvalues (omitted zeros change nothing). If only a truncated list is available, dividing by its sum measures variance within that list and can overstate the fraction of total variance.

Original spectrum: (9,4,1,.5,.5)

Total variance is 15. Keeping two components explains 13/15 ≈ 86.67% and leaves training loss 2. A 90% target needs three components, since 14/15 ≈ 93.33%. A 95% target needs four (14.5/15 ≈ 96.67%). A variance threshold is an explicit compression choice; 90% and 95% are examples, not universal rules.

  • The discarded-eigenvalue identity uses the training spectrum and its fitted basis. It is not a formula for arbitrary held-out loss.
  • With a 1/(N−1) sample covariance convention, the mean per-case squared loss is ((N−1)/N) times the discarded sample eigenvalue sum. Variance fractions do not change.
  • If total variance is zero, the fraction is undefined: all centered observations are identical. Report that directly instead of dividing by zero.
  • PC scores are uncorrelated on the training set; PCA does not automatically make them unit variance or statistically independent.

§20.1.4.3 · pp. 665–666 / PDF pp. 695–696

Profile likelihood turns “find the elbow” into a calculation.

Let M = Lmax be the number of sorted eigenvalues used. For a candidate split L, group the first L eigenvalues together and the remaining M−L together. Model each group with its own Gaussian mean but the same variance. For this heuristic, eigenvalues are treated as independent within each regime, an approximation the book explicitly acknowledges.

μ₁(L) = (1/L)∑k≤L λk   · Eq. 20.28
μ₂(L) = (1/(M−L))∑k>L λk   · Eq. 20.29
SSE(L) = ∑k≤L(λk−μ₁)² + ∑k>L(λk−μ₂)²
σ̂²(L) = SSE(L)/M   · Eq. 20.30; M, not M−2
ℓ(L) = ∑k≤L log 𝒩(λk | μ₁,σ̂²) + ∑k>L log 𝒩(λk | μ₂,σ̂²)   · Eq. 20.31
When σ̂² > 0: ℓ(L) = −(M/2)[log(2πσ̂²(L))+1]
L* = argmax1≤L<M ℓ(L)

For each candidate, estimate the means and the pooled maximum-likelihood variance, insert them into the likelihood, then compare the resulting scores. “Profile” means the nuisance parameters have been optimized for each L. With a fixed M and positive residual variance, maximizing ℓ is equivalent to minimizing SSE.

Original short example

For (9,8,1,.5), split after L=2: means are 8.5 and .75; SSE = .25+.25+.0625+.0625 = .625; σ̂² = .15625; ℓ(2) ≈ −1.9632. The other candidate scores are about −10.0234 for L=1 and −10.1783 for L=3, so this model selects L*=2.

Boundary and degeneracy clarifications: the text briefly writes k<L / k>L, but the model and equations use k≤L / k>L, covering every value. The text also says to try through L=M; Eq. 20.29 is undefined there. Use 1≤L<M so both groups are nonempty. If SSE=0, the fitted Gaussian variance collapses to zero and there is no finite likelihood maximum: ℓ tends to +∞. Report a degenerate fit rather than silently treating zero as a valid Gaussian variance.

Sharing variance prevents a singleton group from independently collapsing its variance, but cannot prevent collapse when both groups have zero within-group spread. Flat, smooth, or multi-elbow spectra may give an ambiguous or unhelpful split. This is an elbow heuristic on the spectrum, not the likelihood of the original PCA observations and not proof of the true number of factors.

Common mistakes

Keep the spaces and objectives straight.

  • Dropping the mean: a PCA reconstruction is μ+Wz. A loading image is a signed deviation from the mean image.
  • Mixing scores and directions: V contains feature-space directions; US contains example scores. U alone leaves out the singular values.
  • Calling centering standardization: subtracting μ does not remove sensitivity to measurement units.
  • Using a zero Gram eigenvalue: Xᵀu/√α requires α>0 and consistent normalization.
  • Forgetting squares or N: covariance eigenvalues are s²/N under this guide's convention.
  • Expecting reconstruction validation to punish every extra PC: a nested larger orthogonal space improves reconstruction of each point, including noise.
  • Reading variance as label relevance: an important target signal can occupy a low-variance direction.
  • Overstating an elbow: a numerical maximizer can exist even when no compelling change point is present. Inspect the spectrum and the purpose of compression.
  • Using M−2 for profile variance: that is not the MLE in Eq. 20.30; use SSE/M.
